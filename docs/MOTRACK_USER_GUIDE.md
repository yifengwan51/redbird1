# MoTrack 用户使用说明

MoTrack 是一个本地篮球视频剪辑工具。你不需要懂模型或命令行，打开网页、点几下就能得到高光集锦和中文复盘。

## 一、启动

在项目目录执行：

```bash
./run_motrack_web.sh
```

浏览器打开：

```text
http://127.0.0.1:8765/app/index.html
```

看到右上角显示“页面已就绪”就可以开始使用。

## 二、生成第一段高光

1. **选择视频**：页面顶部可以选择 ČBF 3x3 Tour 或 Doug McDermott。
2. **选择分析方式**：
   - **智能 Agent**：使用项目内缓存的视觉分析结果，速度较快。
   - **本地轻量**：完全在本机分析，首次可能需要一两分钟，之后会复用缓存。
3. **选择时长**：点 10/15/20/30/45/60 秒，或在输入框里填 5–60 秒。
4. **选择内容**：
   - **投篮 / 扣篮**：优先找疑似投篮和扣篮。
   - **全部精彩动作**：找所有被识别为篮球动作的片段。
5. 点击 **生成高光**。

生成完成后，右侧的“AI 高光”会自动播放，旁边可以下载 MP4。页面会显示实际生成的时长。

> 只要原片够长，选择 20 秒就会生成约 20 秒的视频。

## 三、用聊天修改高光

在“和 AI 助手聊聊”里直接输入中文，例如：

- 生成 20 秒投篮高光
- 做一个 30 秒精彩集锦
- 找出所有疑似投篮
- 缩短到 10 秒
- 再短一点
- 保留最精彩的 3 个片段
- 解释这段视频
- 导出视频

助手会在当前对话里继续修改同一段视频。点“新对话”可以重新开始。

## 四、看懂结果

- **精彩片段时间轴**：列出 AI 找到的候选片段。点击任意一条，会跳到原片对应位置。
- **智能复盘**：用一段话总结这段视频里最值得关注的片段。
- **技术详情**：默认收起。需要查看模型分数、候选版本和原始数据时再展开。

所有结果都是 **AI 推测**，不代表已经确认进球、球员、球队或回合。重要片段建议回看原片确认。

## 五、分析方式怎么选

| 方式 | 适合场景 | 是否联网 |
|---|---|---|
| 智能 Agent | 已有缓存视觉结果，想快速生成和聊天 | 聊天时会调用已配置模型 |
| 本地轻量 · v1 | 完全离线，识别扣篮/投篮/运球等动作 | 否 |
| 本地轻量 · v2 | 需要更完整的候选和审计信息 | 否 |
| 本地轻量 · HypeCut | 只想按画面/音频变化快速找精彩镜头 | 否 |

### 关于 HypeCut

HypeCut 看的是“画面和声音变化明显不明显”，不是“有没有投篮”。它能快速找出热闹的镜头，但不能告诉你进球与否。结果需要回看确认。

## 六、常见问题

**为什么第一次生成比较慢？**

本地轻量模式第一次要先分析整段视频。分析完成后会缓存，下次会快很多。

**为什么选择 20 秒，最后不是正好 20.000 秒？**

视频编码会造成极小的时长误差，例如 20.02 秒，这是正常的。页面显示的是实际文件时长。

**为什么说是“疑似投篮/扣篮”？**

本地模型只识别通用动作，不能确认是否进球，也不能识别球员身份。因此所有事件都标记为 AI 推测。

**智能 Agent 提示没有缓存怎么办？**

说明当前视频还没有可用的缓存视觉分析。可以切换到“本地轻量”模式，完全在本机分析。

**生成的视频在哪里？**

- 本地轻量：`outputs/lightweight_agent/<会话>/highlights.mp4`
- 智能 Agent：`outputs/web_jobs/<任务>/highlights.mp4`

网页里的“下载 MP4”会指向对应文件。

## 七、安全说明

- 服务只监听本机 `127.0.0.1`，没有登录认证，请勿直接暴露到公网。
- 素材默认留在本机，不会整段上传。
- 智能模式只有发送聊天消息时才会调用已配置的模型。
- API 密钥不会写入网页、日志或输出文件。
